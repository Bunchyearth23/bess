# BESS — Physical engine listening and BeamNG checks

These checks establish user listening and game acceptance. Automated signal tests and ZIP verification are separate evidence. Import your own Automation ZIP, check the displayed engine identity and model assumptions, then compare only **A: original Automation reference** and **B: BESS physical engine**.

## Sound and controls

- [ ] Idle sounds credible without a repeating whistle, beating or crackle.
- [ ] Acceleration, steady RPM, lift-off and recovery stay continuous.
- [ ] Exhaust, intake and mechanical levels change the intended layer.
- [ ] The 19 sound controls produce useful changes; muffler settings act when a muffler is fitted.
- [ ] Listening at 0.8 has no unwanted saturation on the chosen engine and settings.
- [ ] Save/reopen restores the physical controls and correct source ZIP.
- [ ] Wheel adjustments use discrete steps and panel scrolling remains usable.
- [ ] Ten minutes of playback and editing produce no dropouts.

## BeamNG add-on

1. Create a named BESS configuration from the imported vehicle.
2. Keep the original Automation mod enabled beside the add-on ZIP.
3. Select the vehicle configuration marked **(BESS - Profile)**.
4. Listen through idle, acceleration, load, lift-off and gear changes, from cabin, hood and tailpipe views.
5. Compare with the original configuration and check after a save/reload.

- [ ] The vehicle loads without audio errors.
- [ ] Both load rows and all RPM points remain audible without loop clicks.
- [ ] Engine/exhaust levels fit the vehicle's other sounds.
- [ ] Original game startup, turbo and afterfire sounds still work.

Record the vehicle, saved project, RPM/load, control changes, A/B selection and camera with any issue. Physical modeling still contains estimated properties; these checks do not claim exact replication of a real engine.
